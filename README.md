# reserva-salao-mobile1
Nome do Projeto
Gestão de Condomínio – Sistema de Reservas de Salão de Festas

Objetivo
Aplicação destinada ao agendamento, controle e administração do uso do salão de festas do condomínio.
Permite que moradores realizem reservas e que administradores gerenciem usuários, datas e solicitações.

Funcionalidades
Requisitos Funcionais
Cadastro de Usuários
Autenticação
Calendário de Disponibilidade
Solicitação de Reserva
Aprovação de Reservas
Cancelamento
Notificações Automáticas

Regras de Uso
Requisitos Não Funcionais
Usabilidade e Responsividade
Segurança e LGPD

Estrutura de Telas
Página Inicial: apresentação do sistema e dados institucionais
Funcionalidades: visão geral dos recursos
Políticas de Uso: regras e normas do salão
Usuários: cadastro e autenticação
Fale Conosco: envio de mensagens
Solicite sua Reserva: formulário de agendamento
Painel Administrativo: gestão de mensagens, usuários e reservas

Layout (UI/UX)
Interface responsiva e padronizada, com:
Paleta em tons de verde
Cabeçalho fixo e menu horizontal
Formulários verticais
Tabelas para administração
Imagens reais do salão como fundo opcional
